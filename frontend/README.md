# StudyQuest — Frontend Flutter Client

This directory is reserved for the Flutter client app (targeting Android Pad and Android TV).

## Tech Stack
- Flutter & Dart
- Nintendo Switch / Duolingo styled UI (large rounded corners, responsive theme)
- Native Focus Engine for TV D-Pad navigation
- Integrations: media_kit (or similar) for video, syncfusion_flutter_pdfviewer for PDF rendering, printing for wireless printing.
