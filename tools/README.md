# StudyQuest — Tools and Local Helper Scripts

This directory is reserved for local worker pipelines, automation scripts, and maintenance utilities.

## Directory Structure Plan
- `video-pipeline/`: Local Python-based automation pipeline (Whisper for audio-to-text, FFmpeg extraction, metadata packing, upload script).
- `import-scripts/`: Scripts to bulk import records or sync mappings.
- `maintenance/`: System backup, SQLite data verification, and sync check.
