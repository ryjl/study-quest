# 学科级默认 Prompt Seed 内容(模块5 用)

> 本文件是 3 个学科(数学/英语/象棋)的 5 字段 AIConfig seed 内容,供 `SeedDefaultSubjects` 使用。
> 由主会话起草,Agent E 负责落地到 Go 代码。其余 8 个学科本轮只建空记录(AIConfigJSON 留空),架构对齐。
>
> 来源:从 `frontend-admin/src/lib/aiHintTemplates.ts` 现有内容拆分 + 新写 Summary/Advice 字段。

## 拆分原则
- **WhisperHint**:保留现有(transcriber.py 用,术语列表+口音+学科风格,≤240 字)
- **SummaryHint**:**新写**。总结的风格/侧重点(不混题型,不混术语)
- **QuizHint**:从现有提取**题型/难度/出题指引**部分(去掉术语字典)
- **AdviceHint**:**新写**。建议的侧重点/口吻
- **TermDict**:从现有提取**术语字典**部分(车→居、通分→同分)

## 数学(math)

### WhisperHint
```
这是一节数学课。常见术语：通分、约分、公分母、异分母、倒数、绝对值、方程、函数、整数、分数、小数、乘除、积、商、倍。
```

### SummaryHint
```
侧重讲解的解题思路和方法推导过程。如果讲了例题,把例题的解题步骤拆解清楚(第一步做什么、为什么这么做)。公式/定理要写明适用条件和易错前提。
```

### QuizHint
```
题型倾向：计算题、事实性知识点（公式、定义、定理）≥50% 出填空（答案必须唯一，如 ["12","十二"]）；辨析、应用、证明题出选择或多选。
难度：中等偏难。干扰项要基于学生真实的错算理（如通分时分子没乘、符号搞反、小数点错位）。
```

### AdviceHint
```
侧重计算类知识点的巩固建议。如果学生在计算类知识点弱,建议回到视频重看推导过程 + 做同类计算题巩固;概念类弱点建议结合具体例题理解。
```

### TermDict
```
通分 → 勿作"同分"
约分 → 勿作"月分"
公分母 → 勿作"工分母"
倒数 → 勿作"道数"
绝对值 → 勿作"决对值"
```

## 英语(english)

### WhisperHint
```
这是一节英语课，老师用中文讲解，音频里会夹带英文单词和句子。常见语法术语：时态、语态、从句、分词、动名词、虚拟语气。
```

### SummaryHint
```
侧重语法规则和用法辨析。如果讲了语法点,把规则、适用场景、和易混语法的区别讲清楚。例句要保留(英中对照)。
```

### QuizHint
```
题型倾向：语法辨析、词义选择、完形填空为主（选择）；单词拼写、动词变形用填空。
难度：中等。干扰项要是真实的语法错误（时态混用、单复数错误、介词搭配错误）。
```

### AdviceHint
```
侧重语法应用和词汇积累建议。语法弱点建议结合例句记忆 + 造句练习;词汇弱点建议在语境中记单词而非死背。
```

### TermDict
```
英文学科术语按需纠正;中文讲解部分的同音错字按常识纠正。
```

## 象棋(xiagnqi / 注意 key 要对应 SeedDefaultSubjects 里的)

> 注意:SeedDefaultSubjects 里没有"象棋"这个系统学科(系统学科是语数英等)。
> 象棋是**自定义学科**,admin 自己建的。所以象棋的 seed 不能放进 SeedDefaultSubjects(那是系统学科)。
> 处理方式:象棋模板保留在前端 `aiHintTemplates.ts`(getSubjectTemplate 按 label 包含"象棋"匹配),不走后端 Subject.AIConfig。
> 或者:如果用户想要象棋也走后端,可以在 SeedDefaultSubjects 里加一个 `{Key:"xiangqi", Label:"象棋", ...}` 系统学科。
> **决策留给用户**:象棋要不要加进系统学科 seed?如果要,用下面的内容。

### WhisperHint
```
这是一节中国象棋课。常见术语：车马炮兵卒将帅士仕相象，屏风马、中炮、巡河炮、过宫炮、反宫马、盘头马、飞相局、仙人指路、将军、绝杀、和棋。
```

### SummaryHint
```
侧重开局原理、战术思路和局面判断。如果讲了具体走法,写明是哪个局面下的走法、目的是什么。术语一律用规范写法(车不写居)。
```

### QuizHint
```
题型倾向：局面判断、走法辨析、战术识别、开局原理为主；少出纯规则记忆题。可用多选题考"以下哪些是某开局的特征"。
难度：偏难。题干必须写明具体局面或本课讲到的位置，禁止孤立问"为什么走某步"——学生隔几天回来不记得指哪段。
```

### AdviceHint
```
侧重实战练习建议。象棋是技能类学科,弱点建议多做实战对局 + 复盘;开局类弱点建议记住几种主流开局的变化。
```

### TermDict
```
车 → 字幕常误作"居"（如"居二平七"应为"车二平七"）
和棋 → 字幕常误作"合棋"
马 → 字幕常误作"码"
炮 → 字幕常误作"跑"
另外注意区分：将/帅、士/仕、相/象（红黑两方叫法不同）
```

1. `SeedDefaultSubjects`(`backend/internal/service/subject_service.go:179`)现在对已存在的系统学科**跳过**(uniqueIndex collision)。要改逻辑:对已存在的系统学科,如果 `AIConfigJSON` 为空,回填上面数学/英语的内容(不覆盖 admin 已配的)。

2. 数学(math)、英语(english)的 key 已在 SeedDefaultSubjects 里(L182-183),直接给这两个 Subject 的 `AIConfigJSON` 填上面的 5 字段(序列化成 JSON)。

4. 其余 8 个系统学科(语文/物理/化学/生物/历史/地理/政治/课外百科):只建记录,AIConfigJSON 留空。

5. AIConfigJSON 的 JSON 格式示例(数学):
```json
{"whisper_hint":"这是一节数学课...","summary_hint":"侧重讲解的解题思路...","quiz_hint":"题型倾向：计算题...","advice_hint":"侧重计算类知识点的巩固...","term_dict":"通分 → 勿作\"同分\"\n约分 → 勿作\"月分\"..."}
```
注意 Go raw string 里不好写,用普通字符串 + `\n` 转义,或者用 model.AIConfig struct + SetAIConfig 序列化(推荐,避免转义地狱)。
